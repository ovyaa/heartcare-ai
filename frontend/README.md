# HeartCare AI

HeartCare AI is a Machine Learning based web application that predicts the risk of heart disease based on user health information.

## Features

- Heart disease risk prediction
- Simple and user-friendly interface
- Prediction results
- Dashboard
- Prediction history
- Responsive design

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Python
- Machine Learning
- Vercel

## Live Demo

https://heartcare-ai-phi.vercel.app/

## Project Type

Machine Learning / Data Science Project
